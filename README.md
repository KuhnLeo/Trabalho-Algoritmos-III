# Trabalho Estrutura de Dados

Descrição
- Programa em C++ que avalia os diferentes métodos de ordenação estudados em aula:
- Programa foi dividido em 3 partes diferentes mais o main. Cada uma tem uma função diferente para auxiliar o resultado

Implementação do projeto

- ['Trabalho-Algoritmos-III//main.cpp'](Trabalho-Algoritmos-III/main.cpp)


Para executar o software é necessário alterar no código do arquivo main o tipo de pré-ordenação do array desejada. Por exemplo, a função deve ser alternada entre 'listaCrescente()', 'listaDecrescente()', 'listaAleatoriaComRepeticao()' e 'listaAleatoriaSemRepeticao()'.

Para valores muito pequenos, principalmente com relação aos arrays de tamanho de até 256, o programa pode não conseguir registrar o tempo com exatidão por causa da biblioteca. Às vezes valores pequenos como 350ns podem ser arrendodados para 0 através da integração
